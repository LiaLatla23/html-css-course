# HTML & CSS Course

En este repositorio documentaré mi progreso y almacenaré todos los ejercicios y proyectos que desarrolle durante el curso de **HTML y CSS** de SuperSimpleDev, que estoy siguiendo en YouTube.

El curso tiene una duración de **6 horas y 31 minutos** y está dividido en 17 lecciones que combinan explicaciones teóricas y ejercicios prácticos. Como proyecto final, desarrollaré una página web inspirada en la interfaz de YouTube.

### Contenido del repositorio

- **Lecciones:** prácticas y ejemplos desarrollados durante las 17 lecciones.
- **Ejercicios:** actividades para poner en práctica los conceptos aprendidos.
- **Proyecto final:** recreación de la interfaz de YouTube utilizando HTML y CSS.

### Objetivo

Aprender y comprender los fundamentos de HTML y CSS mediante la práctica, reforzando mis conocimientos de desarrollo web y aplicándolos en proyectos.
